# PoW 提交测试

## 我在哪里提交任务

WCB 平台（web3career.build）→ 课程页面 → Learning 标签 → 点击具体任务 → 提交证明（Submit Proof）。

## 我使用的 proof 类型

根据任务不同，使用以下类型：

| 场景 | proof 类型 | 示例 |
|------|-----------|------|
| 代码/合约部署 | GitHub repo + Etherscan 链接 | smart-contract-deploy.md + 合约地址 |
| 学习笔记 | GitHub 公开笔记 | Web3基础概念卡片、AI基础概念卡片 |
| 交互操作 | 截图 + 交易哈希 | MetaMask 交易截图 + tx hash |
| 工具环境 | 文字说明 + 截图 | 工具准备记录 |

## 审核者需要看到什么

1. **可验证的证据**：公开链接（GitHub、Etherscan），不是本地文件
2. **完成度证明**：不只是"我做了"，而是"这是我在链上/公开可查的结果"
3. **无敏感信息**：私钥、助记词、API Key、token 绝不出现
