AI × Web3 问题地图

5 个核心方向 · AI 能力 × Web3 机制 · 主线: Identity / Reputation / Capability

★ 主线 ② Identity / Reputation

  • • AI: 读取链上行为记录 → 输出信誉评分 + 能力画像
  • • Web3: DID 身份注册 + 不可篡改行为记录
  • • 结合点: AI 分析的是链上真实数据 → 信任闭环
  • • 延伸: Agent 能力声明标准、Agent 黄页

5 个方向的共同规律

  • • AI 提供「理解」：判断、评估、策略
  • • Web3 提供「可信」：公开、不可篡改、可验证
  • • 每个方向都是缺一不可
  • • AI × Web3 不是功能叠加，是互补闭环

产品研究视角

  • • ② 解决的是标准和体验问题
  • • 不是底层密码学，是接口设计问题
  • • Agent 能力声明 = Agent 的 ABI
  • • 用户视角：怎么发现、筛选、信任一个 Agent
