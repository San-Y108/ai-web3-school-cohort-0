# 2026-05-28 学习笔记

## 今日完成

### Week 2｜Wallet / Permission｜Agent 链上动作权限策略（20分）

- 学习了 EOA vs Smart Account 的区别：EOA 只有私钥控制，不能写规则；Smart Account 可以用代码内置权限规则
- 理解了 Permission 不是一次性操作：需要 budget + scope + time + action type + failure handling 组合
- 学习了执行策略分层：Read-only（自动）、Prepare（自动生成不执行）、Write（必须人工确认）
- 学习了 ERC-4337、Safe、Guard 三个机制如何把"信任 agent"变成"验证 agent"
- 产出文件：tasks/agent-wallet-permission-policy.md

### Week 2｜Payment / Commerce｜最小支付与商业流程拆解（20分）

- 学习了 x402 协议：HTTP 402 Payment Required 标准，让 API 服务可以收费，agent 自动付款
- 学习了 MPP（Machine Payments Protocol）：Stripe 出的，让 agent 像人一样完成支付
- 理解了 x402 和 MPP 的区别：x402 解决 seller 端定价交付，MPP 解决 buyer 端 agent 支付
- 设计了最小 commerce flow：报价→预算授权→执行→交付→验收→付款/退款/争议→记录证明
- 学习了验收和争议是 x402 和 MPP 都没有内置解决的环节，需要 reputation 和人工兜底
- 产出文件：tasks/payment-commerce-flow.md

### 概念学习

- 验收 vs 付款的先后顺序：必须先验收再付款，因为一旦钱到账就不可逆
- Agent commerce 和普通支付的区别：更有体系，人参与更少
- 报价（对方说的价格）和预算授权（你定的上限）是两件事：报价是外部信息，预算是内部规则
