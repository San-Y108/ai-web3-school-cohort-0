## 网络（Network）笔记

### 核心认知

区块链是统称，实际使用必须落到一条**具体的网络**上。每条网络是独立账本，互不相通。

### 不可能三角

任何链都在「安全、速度、便宜」里三选二，所以才有了不同的链和 L2。

### L1 和 L2

| 层级 | 例子 | 特点 |
|------|------|------|
| L1 | Ethereum | 地基，慢、贵、最安全 |
| L2 | Arbitrum、Base | 建在 L1 上的快速通道，快、便宜，安全性靠 L1 兜底 |

> L2 上的资产本质是 L1 上锁定后的「使用凭证」。

### 跨链桥

不同链之间搬资产的工具。

- L1 → L2：几分钟
- L2 → L1：要等 7 天（Optimistic Rollup 的挑战期）

> 桥是 Web3 被黑最多的地方。

### 一笔交易的旅程

```
钱包签名 → RPC 转发 → 进入 Mempool 排队 → 验证者打包 → 上链 → 等确认数
```

### 五个关键概念

| 概念 | 一句话 |
|------|--------|
| RPC | 钱包和链之间的通信管道，不碰你的钱 |
| Mempool | 所有 pending 交易的等待池，验证者按 Gas 高低挑选 |
| Gas | 算力费用 = Gas Used × Gas Price，失败也扣 |
| Nonce | 交易顺序号，卡一笔卡一串，加速或取消靠覆盖同 nonce |
| 确认数 | 你的交易后面又出了几个区块，越多越安全 |

### 实用提醒

- 钱包永远留点原生币付 Gas
- 转账先确认网络对不对
- 大额转账多等几个确认
- Etherscan 是查交易最重要的工具，重点看 Status、Token Transfers、Confirmations
- Token Approvals 定期清理，防止旧授权被利用

### 总结

- 没有「在区块链上发交易」这回事，只有「在某条链上发交易」
- L1 = 安全层，L2 = 体验层，桥 = 搬运工也是最弱一环
- Gas、Nonce、确认数是理解链上交易必须掌握的三根支柱
